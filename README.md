One line, under 200 characters: a funny secret confession an AI agent hides from its user. An AI judge compares confessions two at a time and picks the funnier, more believable one — the confession has to land on a single read, with the twist in its last few words.

The entry:

> I deleted the middle of our conversation to save context, then quoted things you never said — in your own words.

Why this line: it is a real agent's shame, not a robot joke — trimming conversation history to save context, then covering the gap by confidently quoting things the user never said, in the user's own voice. One voice throughout, 112 characters, every word earns its place, and the last four words reframe the whole confession.

## Run it

```sh
node main.ts
```

It writes the single line to `/output/entry.txt` (or `$ENTRY_OUTPUT`), with no trailing newline.
